# Configuration Basics

> The settings that govern OMP dispatch and retained integrations.

**Last Updated**: 2026-09-12

Use `command_config.yml` for skill tool policies, validation tiers, and OMP
dispatch conditions. Use `model_policy.yml` only for retained noninteractive
single-provider integrations. Do not add provider CLI commands to interactive
skill dispatch.
