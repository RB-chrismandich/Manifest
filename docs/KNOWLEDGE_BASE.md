### ANTI-001: Unquoted variable expansion in shell commands

- **Category**: antipattern
- **Language**: bash
- **Severity**: high
- **Occurrences**: 8
- **First seen**: 2026-01-01
- **Last seen**: 2026-02-11

**Problem**: User-controlled values passed to bash -c, eval, or unquoted in command
strings cause command injection (CWE-78). Always quote variables; use arrays for command
arguments; avoid bash -c with interpolated strings.

**Tags**: security, injection, shellcheck, SC2086

### ANTI-002: Insecure temporary file/directory creation

- **Category**: antipattern
- **Language**: bash
- **Severity**: high
- **Occurrences**: 3
- **First seen**: 2026-01-15
- **Last seen**: 2026-02-05

**Problem**: Using predictable temp paths or mkdir without mktemp enables symlink
attacks (CWE-377). Always use mktemp -d with templates; set umask 0077; use trap
for cleanup.

**Tags**: security, temp-files, CWE-377, mktemp

### ANTI-003: Stale file-path references in pre-commit hooks

- **Category**: antipattern
- **Language**: yaml
- **Severity**: high
- **Occurrences**: 3
- **First seen**: 2026-02-11
- **Last seen**: 2026-02-11

**Problem**: Local pre-commit hooks reference old directory paths after refactors,
causing hooks to silently never match any files. Update all path patterns in
.pre-commit-config.yaml as part of every directory restructuring; add a CI check
that validates hook file patterns match existing paths.

**Tags**: architecture, pre-commit, file-paths, refactoring

### ANTI-004: Markdown table column style violations (MD060)

- **Category**: antipattern
- **Language**: markdown
- **Severity**: low
- **Occurrences**: 902
- **First seen**: 2026-01-01
- **Last seen**: 2026-02-11

**Problem**: Tables use compact pipe style (no spaces around pipes in separator rows)
which violates markdownlint MD060. Not auto-fixable by --fix. Either add MD060: false
to .markdownlintrc or reformat all table separator rows.

**Tags**: naming, markdownlint, MD060, formatting

### ANTI-005: Documentation path drift after directory moves

- **Category**: antipattern
- **Language**: markdown
- **Severity**: medium
- **Occurrences**: 9
- **First seen**: 2026-02-11
- **Last seen**: 2026-02-11

**Problem**: After moving files to new directories, documentation references to old
paths remain stale across multiple files. Create a checklist or script that greps
for old path prefixes after any directory restructuring commit.

**Tags**: architecture, documentation, refactoring, stale-paths
