### ANTI-001: Unquoted variable expansion in shell commands

- **Category**: antipattern
- **Language**: bash
- **Severity**: critical
- **Occurrences**: 8
- **First seen**: 2026-01-01
- **Last seen**: 2026-02-11

**Problem**: User-controlled values passed to bash -c, eval, or unquoted in command strings cause command
injection (CWE-78). Always quote variables; use arrays for command arguments; avoid bash -c with interpolated
strings.

**Do this instead**: Never interpolate untrusted values into commands or queries: quote all shell expansions,
pass argv arrays (no shell=True / -c), and use parameterized queries or prepared statements for SQL.

**Tags**: security, injection, shellcheck, SC2086

### ANTI-002: Insecure temporary file/directory creation

- **Category**: antipattern
- **Language**: bash
- **Severity**: high
- **Occurrences**: 3
- **First seen**: 2026-01-15
- **Last seen**: 2026-02-05

**Problem**: Using predictable temp paths or mkdir without mktemp enables symlink attacks (CWE-377). Always
use mktemp -d with templates; set umask 0077; use trap for cleanup.

**Do this instead**: Create temp files/dirs with mktemp (or the language's tempfile API), set a restrictive
umask, and register cleanup (trap/finally) so paths are unpredictable and never leak.

**Tags**: security, temp-files, CWE-377, mktemp
