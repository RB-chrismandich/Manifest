# Finding Triage Dispatch

For three or more candidate findings, triage one finding per unit with
adversarial verification, then aggregate structured verdicts. Below that
threshold, triage inline. If native dispatch (no Agent/Task tool, or a failed
dispatch attempt) or structured output is unavailable, do the same work
inline, one finding at a time, and report `DEGRADED`.

A dispatched reviewer completes its assigned triage directly and does not
re-dispatch.
