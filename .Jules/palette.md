# Palette's Journal

## 2026-02-06 - Initial Setup
**Learning:** UX improvements in CLI tools are just as critical as web UIs.
**Action:** When working on CLI scripts, prioritize readability (colors, spacing) and explicit user guidance (defaults, help text).

## 2026-02-06 - CLI Loading States
**Learning:** Users lack confidence when CLI tools run long processes without clear success/failure indicators or hidden background logs.
**Action:** Implement Braille spinners, hide cursors during execution, and only surface error logs when background tasks fail.
